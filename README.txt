NETCC STATUS
------------
Your Sparky Mate NQ is preparing an application to become a New Energy Tech Consumer Code (NETCC) Approved Seller. The website does NOT claim the business is currently NETCC approved.

The complaints page has been strengthened to support the application process and includes clear complaint lodgement, desired outcome, acknowledgement, investigation, safety prioritisation, progress communication, outcome, review, records and privacy information.

1. The NETCC application requires a formal complaints handling procedure as a business document. This customer-facing webpage supports that process but is not a substitute for the formal internal procedure/document submitted with the application.
2. The website contact form is currently front-end only and is not connected to an email/CRM/form-processing service. Phone and email complaint links work.
3. Once NETCC approval is formally granted, update the website to accurately state Approved Seller status and add the appropriate NETCC escalation pathway.
